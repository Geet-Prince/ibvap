# Website / Dashboard — Service README

**Owner:** New Member #6  
**Status:** Phase 1 — In Development

---

## Purpose
HQ operator-facing web dashboard. Consumes Alarm Manager's WebSocket/REST API only —
never touches any AI module directly.

## Features
- Camera grid with status colours (green/amber/red/gray)
- Live Active Alerts panel (WebSocket-fed, sorted by severity)
- Alert detail: snapshot carousel + clip player + Acknowledge/Escalate/Close
- Search/filter over events (camera, date, type, severity, status)

## Tech Stack
- React (Vite)
- WebSocket for live alert feed
- REST for historical queries

## Starting Immediately (no Alarm Manager needed yet)
Build against mocked alert payloads matching the Alarm Manager's OpenAPI spec.
The OpenAPI spec is auto-generated by FastAPI — once the AM owner has a stub,
pull the spec from `/openapi.json`.
